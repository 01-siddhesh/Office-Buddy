# Work-Bond

WorkBond is an Android app built to help colleagues at LTIMindtree connect with each other based on shared hobbies, interests, and hometown. Users can find and connect with buddies, join office events, and plan travel with coworkers.

## Features

- Signup and login using Firebase Authentication
- User profiles with department, bio, hobbies, movies, and hometown
- Send and accept buddy connection requests
- Friends list to manage accepted connections
- Browse and join office events by category
- Travel Buddy feature to post and join trips with coworkers, including transport mode, available seats, and shared expenses

## Tech Stack

- Kotlin
- Jetpack Compose
- MVVM Architecture
- Firebase Authentication and Firestore
- Navigation Compose
- Coil for image loading

## Getting Started

1. Clone the repository
2. Open in Android Studio
3. Add your own google-services.json file under app/
4. Sync Gradle and run
